# مبادرة أُفُق • Ofoq Initiative
## مسيرة التوحيد واكتشاف النفط (1902 - 1938) | The Path of Unification & Oil Discovery

موقع وثائقي تفاعلي ملحمي يروي تاريخ توحيد المملكة العربية السعودية ومسيرة البناء التي قادها الملك المؤسس عبدالعزيز بن عبدالرحمن آل سعود (1902–1932م)، وصولاً إلى قصة اكتشاف النفط التجاري في بئر الدمام رقم 7 (بئر الخير) عام 1938م.

---

### ✨ مميزات الموقع | Features
- 🌐 **دعم كامل للغتين (Bilingual)**: واجهة كاملة باللغتين العربية والإنجليزية مع دعم اتجاه النصوص (RTL / LTR).
- ⚙️ **محاكي بئر الدمام رقم 7 التفاعلي (Interactive Well Simulator)**: محاكاة تفاعلية فريدة للحفر مع صوت ميكانيكي واهتزازات واقعية (Web Audio API) والنزول عبر الطبقات الجيولوجية حتى عمق 1,441 متراً.
- 👥 **رواد الاكتشاف (The Pioneers)**: تسليط الضوء على التحالف التاريخي الأسطوري بين الجيولوجي الأمريكي **ماكس ستاينكي** وخبير الصحراء والملاح السعودي **خميس بن رمثان**.
- 📜 **معضلة عام 1937 التفاعلية**: استعراض برقية سان فرانسيسكو وقرار الإصرار على مواصلة الحفر بدلاً من الانسحاب.
- 📱 **تصميم فائق الدقة والاستجابة (Responsive UI)**: تجربة مستخدم سينمائية ومتقنة على جميع مقاسات الشاشات والهواتف الذكية.

### 🚀 تشغيل الموقع محلياً | Local Development
لا يحتاج الموقع إلى أي خوادم أو حزم تثبيت معقدة (Vanilla HTML/CSS/JS):
1. قم بفتح ملف `index.html` مباشرة في أي متصفح حديث (Chrome, Safari, Firefox, Edge).
2. أو تشغيل خادم محلي سريع عبر بايثون:
```bash
python3 -m http.server 8000
```
ثم فتح المتصفح على: `http://localhost:8000`

---

### 🌐 النشر على GitHub Pages
1. ارفع هذا المشروع إلى مستودع (Repository) على حسابك في GitHub.
2. توجه إلى **Settings** > **Pages**.
3. تحت **Branch**، اختر `main` واضغط **Save**.
4. سيصبح موقعك متاحاً مجاناً عبر رابط GitHub Pages:  
   `https://<YOUR-USERNAME>.github.io/<REPO-NAME>/`
